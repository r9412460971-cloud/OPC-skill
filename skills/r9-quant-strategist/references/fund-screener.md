# 基金筛选器参考手册

## 分析维度详解

### 1. 业绩分析

计算各基金在 1 年、3 年、5 年、10 年（如有）的：

- **年化回报**：几何平均年化收益率
- **基准**：基金合同基准（如沪深 300 指数收益率 ×80% + 中证全债指数 ×20%）
- **超额收益**：基金年化回报 - 基准年化回报
- **滚动年度收益**：最近 5 年每年收益

年化回报公式：
```
年化回报 = (期末净值 / 期初净值)^(252 / 交易日数) - 1
```

### 2. 风险调整后回报

| 指标 | 公式 | 解读 |
|------|------|------|
| **夏普比率 Sharpe** | (年化回报 - 无风险利率) / 年化波动率 | 单位总风险超额收益；Rf 默认 2.5% |
| **索提诺比率 Sortino** | (年化回报 - 无风险利率) / 下行标准差 | 仅惩罚下行波动 |
| **卡玛比率 Calmar** | 年化回报 / 最大回撤绝对值 | 单位最大回撤收益 |

### 3. 回撤历史

- **最大回撤 Max Drawdown**：区间内最高点到最低点的最大跌幅
- **平均回撤 Average Drawdown**：所有回撤的平均值
- **最大回撤恢复时间**：从最大回撤低点回到前期高点所需交易日数
- **当前回撤**：当前净值距离前期高点的回撤

### 4. 波动率特征

- **年化波动率**：日收益标准差 × √252
- **下行标准差**：仅负收益日标准差 × √252
- **与同业对比**：同策略分类基金中位数、75 分位、25 分位
- **与沪深 300 对比**：相对波动率 = 基金年化波动率 / 沪深 300 年化波动率

### 5. 相关性分析

计算基金与以下资产/指数的滚动相关性（默认 2 年，252 个交易日）：

- 沪深 300（股票 beta）
- 中证全债 / 中债总指数（债券暴露）
- 同类基金平均（策略纯度）
- 中证 500 / 中证 1000（大小盘风格）
- 南华商品指数（商品 CTA 暴露，如适用）

### 6. Alpha 生成能力

使用单因子 CAPM 或多因子模型：

**CAPM Alpha**：
```
基金日超额收益 = Alpha + Beta × 市场日超额收益 + 残差
```

**多因子 Alpha**（可选）：
- 市场因子（MKT）
- 规模因子（SMB）
- 价值因子（HML）
- 动量因子（MOM）

输出：
- Alpha（年化）
- Beta
- 信息比率 IR = Alpha / 跟踪误差
- 跟踪误差 = 基金收益与基准收益差值的标准差（年化）

### 7. 费率结构对比

| 费用类型 | 说明 |
|----------|------|
| 管理费 | 年费率 |
| 托管费 | 年费率 |
| 申购费 | 前端费率（通常按金额阶梯） |
| 赎回费 | 持有期越短费率越高 |
| 销售服务费 | C 类份额常见 |
| **总持有成本估算** | 管理费 + 托管费 + 申赎费摊薄 |

净费后回报 = 费前回报 - 估算年费率。

### 8. 策略分类与规模趋势

- **策略分类**：股票型、混合型、债券型、指数型、QDII、FOF、量化等
- **规模趋势**：近 4 个季度规模变化
- **份额变化**：近 4 个季度基金份额变化率

### 9. 风险警示

对每个基金扫描以下风险信号：

| 风险类型 | 判断标准 | 输出 |
|----------|----------|------|
| **集中持仓** | 前十大占净值比 >60% 或单一标的 >10% | 高/中/低 |
| **关键人风险** | 基金经理任职 <2 年或近期变更 | 是/否 |
| **流动性错配** | 基金规模较大但重仓小市值/低流动性标的 | 高/中/低 |
| **风格漂移** | 近 4 个季度风格因子暴露显著变化 | 高/中/低 |

### 十、配置建议

根据投资标准给出：

- **核心配置**：评分最高、风险收益比最优的基金
- **卫星配置**：可作为补充的基金
- **回避**：风险警示较高或业绩持续落后的基金
- **建议仓位上限**：基于波动率、相关性、流动性

### 十一、风险提示

- 历史业绩不代表未来
- 定量筛选需结合定性尽调
- 费率数据可能变动
- 风格漂移和关键人风险需持续监控

## 数据获取建议

### AKShare 接口

```python
import akshare as ak

# 基金历史净值
ak.fund_em_open_fund_info(fund="基金代码", indicator="单位净值走势")

# 基金基本信息
ak.fund_name_em()

# 基金业绩排名
ak.fund_em_performance_rank()

# 基金费率
ak.fund_em_fee()
```

### 天天基金网

- 净值：`api.fund.eastmoney.com/f10/lsjz`
- 业绩排名：`fund.eastmoney.com/data/fundranking.html`
- 基金经理：`fundf10.eastmoney.com/jjjl_{code}.html`

### 计算依赖

- `pandas`：数据处理
- `numpy`：数值计算
- `scipy.stats`：统计检验
- `matplotlib/seaborn`：图表（可选）

### 指数数据

- 沪深 300：`ak.index_zh_a_hist(symbol="000300", period="daily")`
- 中证 500：`ak.index_zh_a_hist(symbol="000905", period="daily")`
- 中证全债：`ak.bond_zh_index()`
