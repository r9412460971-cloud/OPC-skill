# 财报催化剂研究员参考手册

## 分析维度详解

### 1. 催化剂识别

未来 90 天内可能推动股价的所有事件：

| 事件类型 | 示例 | 影响方向 |
|----------|------|----------|
| 季度/年度财报 | Q1/Q2/Q3 季报、年报 | 双向 |
| 业绩预增/预减公告 | 交易所强制披露 | 双向 |
| 股东大会 | 分红、定增、回购方案 | 双向 |
| 产品发布 / 订单公告 | 新品上市、大订单 | 多/空 |
| 监管决定 | 药品审批、牌照、反垄断 | 多/空 |
| 行业展会 / 投资者日 | 指引更新、战略披露 | 双向 |
| 宏观经济数据 | 行业 PMI、价格数据 | 双向 |
| 供应链事件 | 客户/供应商业绩、库存 | 双向 |

### 2. 盈利预测分析

- **机构投资者共识**：Wind/东方财富一致预期（营收、净利润、EPS）
- **渠道检查暗示**：
  - 供应链上下游公司财报/指引
  - 行业协会数据
  - 高频价格/销量数据
  - 门店/渠道草根调研
- **预期差方向**：渠道检查 vs 共识的差距

### 3. 管理层指引历史

评估管理层历史指引质量：

| 类型 | 特征 | 投资含义 |
|------|------|----------|
| 保守型 | 实际业绩持续超预期 | 指引下调未必悲观 |
| 准确型 | 实际业绩接近指引 | 可信度高 |
| 过度承诺型 | 实际业绩持续低于指引 | 指引上调需谨慎采信 |

统计近 8 个季度：指引值 vs 实际值偏差。

### 4. 供应链信号

- 上游供应商订单/产能利用率变化
- 下游客户采购/库存变化
- 同业公司财报中对该公司的提及
- 海关、运价、价格指数等高频数据

### 5. 内幕交易活动

基于公开披露：

- 大股东增减持
- 高管增减持
- 员工持股计划
- 回购/增持计划

注意：需结合价格和时间判断信号方向。

### 6. 做空兴趣轨迹

对于 A 股：

- 融资融券余额变化
- 融券卖出量变化
- 大宗交易折价率
- 北向资金流向

对于港股/中概股：

- 融券余额（Short Interest）
- 看跌/看涨期权比（Put/Call Ratio）

### 7. 期权市场异常

对于 A 股（50ETF/300ETF 期权间接反映）：

- 隐含波动率变化
- Put/Call 比变化
- 期权成交量异动

对于港股/美股：

- 个股期权隐含波动率
- 跨式组合价格（预期波动）
- 大额期权成交方向

### 8. 同业可比公司读数

选取 3-5 家可比公司，分析：

- 已披露财报的业绩趋势
- 管理层指引变化
- 估值倍数变化
- 股价对业绩的反应

### 9. 共识修订趋势

- 近 4 周 EPS 一致预期上调/下调比例
- 目标价上调/下调比例
- 评级上调/下调数量

### 10. 交易结构

基于催化剂构建交易方案：

| 要素 | 说明 |
|------|------|
| **方向** | 做多 / 做空 / 观望 |
| **仓位** | 基于波动率和信心度（如 1%-3% 风险预算） |
| **入场点** | 催化剂前 N 个交易日 / 事件触发后突破 |
| **止损** | 技术位 / 事件证伪 / 波动率阈值 |
| **止盈** | 目标价 / 事件兑现后减仓 |
| **时间窗口** | 事件前 / 事件后持有期 |
| **对冲** | 行业 ETF / 指数期货 / 期权保护 |

## 数据获取建议

### AKShare 接口

```python
import akshare as ak

# A 股公司公告
ak.stock_notice_report(symbol="股票代码", date="报告期")

# 业绩预告
ak.stock_yjbb_em(date="报告期")

# 股东增减持
ak.stock_gdzc_em()

# 融资融券
ak.stock_margin_detail_szse(symbol="股票代码")

# 北向资金持股
ak.stock_hsgt_hist_em(symbol="沪股通/深股通")
```
