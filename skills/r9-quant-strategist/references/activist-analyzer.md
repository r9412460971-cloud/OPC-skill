# 激进投资者分析器参考手册

## 分析维度详解

### 1. 激进投资者画像

| 维度 | 内容 |
|------|------|
| 身份 | 对冲基金、私募股权、个人大股东、主权基金等 |
| 管理规模 | AUM |
| 投资风格 | 激进改革、董事会席位、拆分出售、资本回报、ESG 等 |
| 历史战绩 | 过往激进投资案例数量、胜率 |
| 平均持有期 | 短期（<1 年）/ 中期（1-3 年）/ 长期（>3 年） |
| 地域偏好 | 美股、港股、A 股等 |
| 资金来源与杠杆 | 自有资金、外部 LP、杠杆水平 |

胜率统计：
- **完全成功**：主要诉求全部实现，股价显著跑赢
- **部分成功**：部分诉求实现，股价小幅跑赢
- **失败**：诉求未实现，股价跑输或亏损退出

### 2. 论点拆解

激进投资者公开信中通常提出的诉求：

| 诉求类型 | 示例 | 价值释放逻辑 |
|----------|------|--------------|
| 董事会改组 | 更换 CEO、增加独立董事 | 改善治理 |
| 资本结构 | 增发回购、提高分红、发债 | 提升股东回报 |
| 战略调整 | 剥离非核心资产、聚焦主业 | 提升 ROE |
| 运营改进 | 降本增效、供应链优化 | 提升利润率 |
| 出售公司 | 整体出售或合并 | 溢价变现 |
| ESG | 环境、社会责任改进 | 降低风险溢价 |

对每个诉求评估：
- 合理性
- 管理层抵触程度
- 其他股东支持可能性
- 监管/法律障碍

### 3. 管理层回应与反驳理由

收集管理层回应：

- 公开声明 / 投资者电话会
- 代理声明（Proxy Statement）
- 与激进投资者私下沟通结果

评估管理层反驳的有效性：
- 是否有数据和事实支撑
- 是否回避核心问题
- 股东投票历史是否支持管理层

计算当前估值 vs 激进投资者主张估值：

| 估值方法 | 当前值 | 激进目标 | 差距 |
|----------|--------|----------|------|
| PE | ... | ... | ... |
| EV/EBITDA | ... | ... | ... |
|  sum-of-the-parts | ... | ... | ... |
|  DCF | ... | ... | ... |

激进投资者通常主张的估值提升来源：
- 利润率改善
- 资本回报率提升
- 资产剥离/重组
- 分红/回购增加

### 5. 代理权争夺概率与投票预测

对于上市公司：

- **代理权争夺（Proxy Fight）概率**：高/中/低
- **关键投票日期**：年度股东大会、特别股东大会
- **机构股东站队**：前十大机构股东历史投票倾向
- **散户持股比例**：散户通常支持管理层或随大流
- ** ISS / Glass Lewis 建议**： proxy advisory 机构建议

### 8. 下行情景

激进投资失败后的可能后果：

- 激进投资者撤资导致股价下跌
- 公司战略混乱、管理层分心
- 法律诉讼成本
- 市场信心受损
- 估值回归原位甚至折价

### 9. 机构持仓站队分析

分析公司前十大流通股东/机构持仓：

- 哪些机构可能支持激进投资者
- 哪些机构通常支持管理层
- 近期机构增减持方向
- 北向资金 / 南向资金态度

### 10. 交易建议

综合以上分析给出：

| 建议 | 条件 |
|------|------|
| **买入** | 激进投资者胜率高、估值差距大、催化剂临近 |
| **观望** | 结果高度不确定、股价已部分反映预期 |
| **回避** | 激进投资者胜率低、管理层强硬、下行情景严重 |

进场点建议：
- 激进消息披露后回调买入
- 关键投票前事件驱动建仓
- 设置止损：激进投资者退出、关键投票失败
