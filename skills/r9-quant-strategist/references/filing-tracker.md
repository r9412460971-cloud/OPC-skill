# 备案追踪器参考手册

## 分析维度详解

### 1. 前 10 大持仓

每只基金季报披露的前十大重仓股/债：

| 字段 | 说明 |
|------|------|
| 代码 | 股票/债券代码（A股 6 位代码 + .SH/.SZ/.BJ） |
| 名称 | 证券简称 |
| 持股数 | 报告期末持有数量（股/张） |
| 仓位价值 | 持股数 × 报告期末收盘价（亿元） |
| 占净值比 | 基金季报披露值 |
| 较上期变化 | 增持/减持/新建/清仓 |

### 2. 新建仓位

本季首次进入前十大重仓的标的。

- 记录：标的代码、名称、占净值比、估算买入金额。
- 信号解读：新买入通常代表基金经理在该季度形成了新的信念；需结合行业与市值判断是主题博弈还是基本面布局。

### 3. 增持 / 减持仓位

- **增持**：占净值比环比提升 >0.5pp（或持股数增加）。
- **减持**：占净值比环比下降 >0.5pp（或持股数减少）。
- 计算变化百分比：`(本期占净值比 - 上期占净值比) / 上期占净值比`（新建仓位标注为 NEW，不计算百分比）。

### 4. 清仓仓位

上期在前十大，本期不在前十大且未出现在完整持仓中（或占比极低）。

- 记录：标的代码、名称、上期占净值比、可能原因。
- 风险信号：高占比仓位的清仓可能意味着基金经理信心逆转或风控砍仓。

### 5. 行业配置分布

将前十大持仓映射到申万一级/二级行业，计算：

- 各行业占净值比合计
- 较上期的行业配置变化
- 前三大重仓行业

### 6. 信念排名（Conviction Ranking）

前十大持仓按占净值比排序：

- **TOP 3 信念仓位**：占净值比最高的 3 只标的，通常占前十大 50% 以上权重。
- **集中度指标**：前十大占净值比合计、前五大占净值比合计、赫芬达尔指数（HHI）。

HHI 计算：
```
HHI = Σ(每只持仓占净值比)^2 × 10000
```
- HHI > 2500：高度集中
- HHI 1500-2500：中度集中
- HHI < 1500：相对分散

### 7. 季度环比变化

对比连续两个季度：

- 持仓数量变化：新增、退出、增持、减持数量统计
- 行业漂移：行业权重变化 >5pp 视为显著漂移
- 风格漂移：价值/成长、大盘/小盘暴露变化（结合持仓市值与估值）

### 8. 重叠分析（Overlap Analysis）

选取同类型基金（同策略分类、同基金公司或同基金经理风格）5 只，计算共同持仓：

- **共同重仓**：3 只及以上基金共同持有的前十大标的
- **共识仓位**：5 只基金均持有的标的（最强信号）
- **分歧仓位**：仅本基金持有，同类型基金均未持有的标的

输出重叠矩阵：行=标的，列=基金，单元格=占净值比。

### 9. 3 个最值得关注的动作及信号

基于以上分析，提炼 3 个最具市场意义的动作：

| 优先级 | 动作 | 信号强度 | 解读 |
|--------|------|----------|------|
| 1 | 例如：大幅增持某行业龙头 | 高/中/低 | ... |
| 2 | 例如：清仓某高估值标的 | 高/中/低 | ... |
| 3 | 例如：与同业形成共识买入 | 高/中/低 | ... |

信号强度判断标准：
- **高**：占净值比变化 >3pp、新建即进入 TOP5、5 只同业基金共同动作
- **中**：占净值比变化 1-3pp、行业配置显著漂移
- **低**：占净值比变化 <1pp、单季度小幅调仓

### 九、风险提示

- 季报披露滞后性（通常为季度结束后 15 个工作日）
- 仅反映前十大持仓，完整持仓未知
- 基金经理可能已在本季度后调仓
- 聪明钱信号不构成投资建议

## 数据获取建议

### AKShare 接口

```python
import akshare as ak

# 基金季报重仓股
ak.fund_portfolio_hold_em(symbol="基金代码", date="报告期")

# 基金行业配置
ak.fund_portfolio_industry_allocation_em(symbol="基金代码", date="报告期")

# 基金资产配置
ak.fund_portfolio_asset_allocation_em(symbol="基金代码", date="报告期")
```

### 天天基金网

- 重仓股：`fundf10.eastmoney.com/FundArchivesDatas.aspx?type=jjcc`
- 行业配置：`fundf10.eastmoney.com/FundArchivesDatas.aspx?type=hytz`
- 资产配置：`fundf10.eastmoney.com/FundArchivesDatas.aspx?type=zcpz`

### Wind / iFinD

如用户有终端，可提取更完整数据：
- 全部持仓（非仅前十大）
- 持股变动明细
- 行业配置 II 级
- 风格归因（Barra / CAMP）
