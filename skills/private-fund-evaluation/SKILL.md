# 私募证券投资基金评价

## 定位

本 skill 面向财富管理、投顾组合、家办/FOF 投研场景，对**私募证券投资基金**做一次性综合评价。与公募基金评价 skill（`fund-r9alpha-evaluation`）互补：私募基金数据更 opaque，因此更强调：
1. **数据来源的可靠性声明**
2. **管理人/创始人/投资经理的横纵分析**
3. **基金策略类型的前置分析**
4. **条款结构、流动性与风险识别**

## 核心原则

### 数据可获得性与准确性

私募基金数据是最大难点。执行前必须明确：

| 数据层级 | 来源 | 可信度 | 注意事项 |
|---------|------|--------|---------|
| **官方一手** | 管理人提供的净值/月报/合同/尽调材料 | ⭐⭐⭐⭐⭐ | 优先采信，但需警惕选择性披露 |
| **监管备案** | 中国基金业协会（amac.org.cn） | ⭐⭐⭐⭐⭐ | 备案真实性、管理人诚信/处罚记录最权威 |
| **专业终端** | Wind、Choice、朝阳永续、私募通 | ⭐⭐⭐⭐☆ | 净值相对完整，但存在滞后、口径差异 |
| **第三方平台** | 私募排排网、好买基金、金斧子等 | ⭐⭐⭐☆☆ | 公开净值可能不完整、存在 Survivorship Bias，需交叉验证 |
| **网络公开** | 访谈、路演、行业报告、新闻报道 | ⭐⭐⭐☆☆ | 可作为定性补充，不能单独作为投资依据 |

**准确性处理规则**：
- 所有数据来源必须在报告中明确标注。
- 净值数据需说明：是否扣费、是否经过审计、更新频率、是否有回填（backfill）。
- 不同来源数据冲突时，优先采信管理人/托管人/协会数据，并在报告中说明差异。
- 无法验证的数据统一标注为「待验证/数据待补」，禁止编造。

## 工作流程

### Step 1: 确认输入
向用户确认（如未明确提供）：
- **基金名称 / 备案编码**（如「高毅晓峰1号 / SXxxxx」）
- **基金管理人**（如 高毅资产）
- **核心投资经理/创始人**（如 邓晓峰）
- **策略类型**（股票多头 / 量化 / CTA / 多策略 / 固收+ / 宏观对冲 / 市场中性 / 套利等）
- **可用数据来源**（管理人材料、协会查询、Wind/Choice、私募排排网、尽调纪要等）
- **输出目录**（默认当前目录）

### Step 2: 管理人（公司）横纵分析
在分析具体基金之前，先分析管理人公司本身。调用 `hv-analysis` 的横纵分析法框架：

**纵向（公司发展史）**：
- 公司成立背景、创始团队构成、发展历程中的关键节点
- 管理规模变化与策略迭代
- 核心人员变动（尤其是投资总监/合伙人的进出）
- 历史上是否出现过合规风险、客户纠纷、业绩爆雷

**横向（同业对比）**：
- 与同类百亿私募对比（投研团队、管理规模、产品线、业绩稳定性）
- 公司核心竞争优势与短板
- 行业口碑、渠道评价、机构资金占比

### Step 3: 核心人物横纵分析
对核心投资经理/创始人进行横纵分析：

**纵向（人物生涯）**：
- 职业履历、投资理念形成过程
- 过往管理产品的完整业绩曲线（含公募/专户/私募阶段）
- 投资风格的演变与稳定性
- 重大决策复盘（成功与失败案例）

**横向（同业对比）**：
- 与同策略顶尖投资经理对比
- 投资方法论的差异（价值投资/成长/量化/宏观等）
- 行业声誉、机构认可度

### Step 4: 策略类型前置分析
在分析具体基金之前，先分析该策略类型本身：

| 策略类型 | 分析重点 |
|---------|---------|
| **股票多头** | 市场 beta 贡献 vs alpha、选股能力、行业集中度、估值偏好 |
| **量化** | 因子暴露、模型迭代、策略容量、换手率、超额衰减 |
| **CTA** | 趋势/套利/基本面子策略、商品/股指覆盖、波动率依赖 |
| **宏观对冲** | 资产轮动、杠杆使用、宏观判断胜率、流动性管理 |
| **市场中性** | 对冲成本、多头 alpha 来源、基差风险、容量限制 |
| **多策略** | 子策略配置逻辑、相关性假设、尾部风险 |
| **固收+** | 债券底仓信用风险、权益增强来源、回撤控制 |
| **套利** | 套利空间来源、资金容量、极端行情下的失效风险 |

分析该策略类型的：**核心收益来源、典型风险、适合的市场环境、容量瓶颈、当前市场拥挤度**。

### Step 5: 基金层面数据收集
按优先级收集：
1. **净值数据**：成立以来/近3年月频或周频净值
2. **基本信息**：成立日期、备案时间、规模、基金经理、托管人、经纪商
3. **策略说明**：基金合同/招募书、策略概述、目标波动/收益、敞口约束
4. **条款信息**：认购起点、锁定期、开放频率、赎回费、管理费、业绩报酬、高水位线
5. **市场信息**：第三方平台排名、同策略竞品表现、渠道反馈

### Step 6: 基金十维评价
将收集到的信息整理到以下十个维度，缺失项标注「数据待补」并说明影响。

#### 1. 基础画像
- 管理人背景（成立时间、股东结构、核心投研履历）
- 基金经理任职稳定性、管理本产品的时长
- 基金备案状态、托管人与运营安排
- 产品规模及规模变化趋势

#### 2. 策略定位
- 策略类型与细分风格
- 目标收益/波动、收益来源、核心假设
- 与同类策略的差异点

#### 3. 收益表现
- 成立以来年化收益、今年以来、去年、近三年收益
- 同策略私募/公募指数对比
- 滚动年度收益分布
- 收益是否来自单一市场 beta 或风格暴露

#### 4. 风险控制
- 最大回撤及回撤发生时间、修复天数
- 年化波动率、下行标准差
- 月度/年度亏损次数与幅度
- 极端行情表现

#### 5. 风险调整收益
- 夏普比率（Rf=2.5%）
- 卡玛比率、索提诺比率
- 盈亏比、月度胜率

#### 6. 策略稳定性与一致性
- 策略风格是否漂移
- 基金经理言论与实际操作是否一致
- 策略容量是否匹配当前规模
- 极端行情下策略逻辑是否仍然成立

#### 7. 管理人质量
- 核心人员稳定性
- 投研团队配置与研究深度
- 激励机制是否与客户利益一致
- 合规记录

#### 8. 条款与流动性
- 锁定期、开放频率、赎回费结构
- 管理费 + 业绩报酬合计成本
- 高水位线与回拨机制
- 赎回门槛与紧急情况流动性安排

#### 9. 运营与透明度
- 信息披露频率与质量
- 估值与审计安排
- 关联交易、利益冲突防范
- 申赎效率与资金安全性

#### 10. 综合评价
- 优势（3-5 条）
- 风险点（3-5 条）
- 适合的投资者画像
- 是否建议配置及仓位上限建议

### Step 7: 生成评价报告
输出一份结构化报告：
- **数据声明**：明确列出所有数据来源、可信度、缺失项
- **管理人横纵分析**
- **核心人物横纵分析**
- **策略类型分析**
- **基金十维评价**
- **关键数据摘要表**
- **风险提示与配置建议**
- **待补数据清单**

输出文件：`{输出目录}/私募基金评价报告_{基金名称}.md`

## 输出要求

- 不要编造净值或业绩数据；无法确认的数据标注为「待补」或「推测」。
- 评价结论必须与可得数据匹配，避免过度推断。
- 对私募基金应更加强调「不买错」而非「选最好」，风险提示要明确。
- 若数据严重不足，直接告知用户无法形成有效评价，列出需要补充的材料。

## 数据来源优先级

1. **管理人提供的净值/月报/合同条款**
2. **中国基金业协会官网**（备案信息、管理人诚信信息）
3. **Wind / Choice / 朝阳永续 / 私募通等专业终端**
4. **私募排排网 / 好买基金 / 金斧子**（交叉参考，谨慎采信）
5. **公开尽调纪要、访谈、路演材料**
6. **网络公开信息**（监管处罚、负面舆情、行业报告）

## 协作 Skill

- 需要管理人/人物深度研究素材 → `hv-analysis`
- 需要量化净值风险指标计算 → `xlsx-author` + Python
- 需要生成 PDF → 使用 Markdown 转 PDF 工具（如 md-to-pdf、Pandoc、Playwright）或 `hv-analysis` 的 PDF 输出模式

## 不适用场景

- 私募股权/创投基金（PE/VC）评价 → 使用 `returns-analysis` 或相关 PE skill
- 公募基金评价 → 使用 `fund-r9alpha-evaluation`
- 已经建立持续跟踪需求 → 后续可升级为私募跟踪 skill
