# 投后客户沟通服务

> **重要合规声明**
> - 本服务由人工智能（AI）生成，仅供理财经理等专业人员内部参考，**不构成投资建议**。
> - 本服务不替代持牌投资顾问、心理咨询师或真实人际支持；涉及用户极端情绪、重大财产损失或自残自杀等情境，应立即引导其联系监护人、紧急联系人或专业人士。
> - 用户可随时通过输入“退出”、“结束”、“停止”等关键词终止服务。
> - 连续使用超过 2 小时，应提醒用户注意休息。

## 概述

本 skill 为理财经理提供标准化的投后客户沟通服务体系，帮助实现从"卖产品"到"卖服务"的转型。

**核心定位**：以每日市场热点为切入点，系统回答投后沟通的三个核心问题，传递专业信息、管理收益预期、应对策略变化。

**输出结构**：
1. 每日市场热点解读（复用 daily-market-hotspot skill）
2. 投后沟通三问：
   - 沟通频率：与客户多长时间沟通一次？
   - 收益满意度：持有人多少收益比较满意？
   - 策略及应对：策略是什么？变化了怎么办？

## 合规边界

1. **AI 身份提示**：所有生成内容应明确标注或由使用方告知客户其由 AI 辅助生成，避免客户误以为是真人投顾一对一沟通。
2. **未成年人保护**：不向未成年人提供虚拟亲密关系服务；向不满十四周岁未成年人相关服务须取得监护人同意。
3. **不诱导情感依赖**：沟通内容应聚焦市场事实、产品运作与策略逻辑，避免使用"永远陪着你""你最懂我"等可能诱导情感依赖的表述。
4. **极端情境处置**：如识别到用户（含理财经理转述的客户）出现极端情绪或自残自杀等表述，应立即停止投资建议类输出，优先输出安抚与求助引导，并建议联系紧急联系人或专业心理援助。
5. **数据安全**：用户交互数据不得未经授权用于模型训练；应提供历史数据复制、删除选项。

## 工作流程

### 第一步：生成每日市场热点

调用 `daily-market-hotspot` skill，基于当日市场素材生成市场热点解读文章。

**操作方式**：
- 若用户已提供市场素材，直接基于素材调用 daily-market-hotspot 的撰写规范
- 若用户未提供素材，引导用户提供或主动搜索当日行情与新闻

**输出要求**：
- 保留 daily-market-hotspot 的完整结构（今日聚焦 + 重点新闻 + 全球市场）
- 保留网络化风格（老登/小登等代称、口语化表达）
- 保留 R9 横纵分析法内核

### 第二步：确定沟通频率

基于客户画像、持仓状态、市场阶段，回答"与客户多长时间沟通一次"。

**分析框架**：参见 [references/communication-frequency.md](references/communication-frequency.md)

**核心逻辑**：
1. 识别客户类型（新客户/老客户/高净值/普通客户）
2. 识别持仓状态（盈利/亏损/回本/刚申购）
3. 识别市场阶段（上涨/下跌/震荡/重大事件）
4. 匹配合适的沟通频率和触达方式

**输出内容**：
- 建议沟通频率（如"本周内电话回访一次"）
- 沟通优先级排序（哪些客户先沟通）
- 沟通方式建议（电话/面访/微信/沟通报告）
- 沟通核心话题（市场解读 + 持仓关怀 + 策略确认）

### 第三步：评估收益满意度

基于产品类型、客户预期、市场环境，回答"持有人多少收益比较满意"。

**分析框架**：参见 [references/return-expectation.md](references/return-expectation.md)

**核心逻辑**：
1. 明确产品属性（固收+/权益/FOF/指数/行业主题）
2. 设定合理收益区间（绝对收益目标 or 相对收益基准）
3. 结合持有期限（短期浮盈 vs 长期复利）
4. 结合市场环境（牛市预期 vs 熊市容忍）

**输出内容**：
- 当前收益是否达到满意区间
- 若未达到：解释原因 + 预期修复时间
- 若已达到：止盈建议 or 继续持有逻辑
- 客户心理安抚话术（避免追涨杀跌）

### 第四步：明确策略及变化应对

清晰陈述当前投资策略，并说明如果发生变化将如何应对。

**分析框架**：参见 [references/strategy-response.md](references/strategy-response.md)

**核心逻辑**：
1. 当前策略陈述（资产配置、风格偏好、行业取向）
2. 策略有效性评估（是否按预期运作）
3. 变化触发条件（什么情况下会调整）
4. 应对措施（调仓逻辑 + 沟通话术 + 客户行动建议）

**输出内容**：
- 当前策略一句话总结
- 策略运作状态（正常/偏离/待观察）
- 若策略变化：变化原因 + 调整方向 + 对客户的影响
- 若策略不变：坚持理由 + 客户应有心态

## 触发条件与响应时效

| 场景 | 触发条件 | 响应时效 |
|------|---------|---------|
| 日常沟通 | 每日开盘后 | 当日 |
| 收益触达 | 收益率≥目标阈值 | T+1日内 |
| 回撤触达 | 回撤≥目标阈值 | 当日 |
| 重大事件 | 市场波动≥3% or 地缘/政策突变 | 事件驱动 |
| 定期回顾 | 周/月/季度约定 | 按约定频率 |

## 关键原则

1. **市场热点是敲门砖**：用每日市场解读打开话题，建立专业形象
2. **三问是核心**：沟通频率、收益预期、策略应对，缺一不可
3. **先说现象再给观点**：不绕弯子，直接亮明态度
4. **预期管理是底线**：反复强调目标非承诺，淡化短期波动
5. **服务而非推销**：以信息传递与预期管理为核心，帮助客户理性决策
6. **风格一致**：市场热点部分用网络化口语，投后部分用专业但易懂的表达
7. **边界清晰**：不替代专业心理咨询，不建立超出投顾服务范围的情感关系
