# 四大使用场景指引与输出模板

按第0步识别的场景选择本文件对应章节加载。每个场景给出：侧重点调整、交汇判断的翻译方式、输出模板。

## 目录

1. 场景A：渠道拜访（基金公司/券商渠道经理）
2. 场景B：网点诊断（总部管理者/营业部总经理）
3. 场景C：竞对摸排（券商/财富管理机构）
4. 场景D：求职尽调（求职者）

---

## 场景A：渠道拜访

**使用者**：基金公司渠道经理、券商产品端、三方财富渠道，拜访该网点谈产品准入/代销/培训合作前。

**侧重点调整**：
- 横轴中"同券商内部坐标"最重要——决定该网点在自家体系内的话语权（能不能推得动产品）
- 纵轴中"负责人背景"权重最高——拜访本质是搞定人
- 补充研判：客群属性与自家产品的匹配度（偏交易型客群的网点卖不动长封闭期产品）

**"对你意味着什么"的翻译**：
- 值不值得跑（投入产出预判）
- 找谁（负责人画像+关键人识别）
- 带什么（产品匹配建议+开场话题素材：利用纵轴挖到的网点近况做破冰）

**输出模板（一页纸速览卡）**：

```
# 拜访速览卡：{券商}{营业部}

画像一句话：{例：成立12年的老牌交易型网点，近三年投顾化转型中，负责人系总部空降}

## 关键信号
| 信号 | 内容 | 来源级别 |
| 执业人数/投顾占比 | ... | 【可查】 |
| 客群属性 | ... | 【推断】依据... |
| 负责人 | ... | 【可查】 |
| 近况动态 | ... | 【可查】 |

## 三个判断
1. 靠什么活着：...
2. 在向哪走：...
3. 拜访策略：值不值得跑 / 找谁 / 带什么产品 / 破冰话题

## 待补充（需现场核实）
- ...
```

## 场景B：网点诊断

**使用者**：券商总部财富管理部、分公司总经理、营业部总经理本人。这是默认场景。

**侧重点调整**：
- 三层坐标都要做扎实，短板定位是核心价值
- 收入结构推演要落到四个收入源的拆解建议（哪块能提、怎么提）
- 建议部分给"90天可改善项"与"需总部支持项"两栏，区分自己能改变的和要改变命的

**输出**：深度报告PDF（完整四章）+ 末尾附"诊断结论与行动清单"：

```
## 诊断结论
- 坐标定位：{同商圈X家中游/同券商体系内第二梯队/...}
- 核心短板：...
- 被低估的优势：...

## 行动清单
| 优先级 | 事项 | 类型 |
| 90天可改善 | ... | 网点自主 |
| 需总部支持 | ... | 资源申请 |
```

## 场景C：竞对摸排

**使用者**：同城其他券商营业部、财富管理机构区域负责人。

**侧重点调整**：
- 横轴"同商圈竞对"位置互换——把目标网点放进"我"的坐标系里看威胁
- 重点研判：对方在抢什么客群（龙虎榜/产品结构推断）、打法的可持续性（总部资源依赖度）
- 给出"应对三选"：正面抢 / 错位竞争 / 无视（对方威胁有限时明确说）

**输出**：深度报告PDF，交汇部分改为"威胁评估 + 应对建议"。

## 场景D：求职尽调

**使用者**：拿到该网点offer或考虑跳槽的从业者。

**侧重点调整**：
- 权重最高：团队稳定性（人员流动率）、负责人风格与任职时长、网点在总部体系内的存续风险（收缩期券商的尾部网点有撤并风险）
- 纵轴重点看"趋势方向"而非历史荣誉

**"对你意味着什么"的翻译**：
- 平台判断：这个网点处于上升/维持/衰退哪个阶段
- 成长空间：投顾化程度决定新人成长环境（有无成熟投顾可跟随）
- 风险提示：撤并风险、恶性处罚史、高流动率警示

**输出**：一页纸速览卡 + "接offer前建议当面核实的5个问题"清单。
