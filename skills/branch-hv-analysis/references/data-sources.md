## 1. 证券业协会从业人员公示（P0，最重要）

**网址**：中国证券业协会官网 → 从业人员信息公示（www.sac.net.cn）

**查什么**：
- 按机构名称+营业部名称筛选该网点全部执业人员
- 记录：总人数、投资顾问人数、一般证券业务人数、经纪人人数
- 关键人：负责人（通常登记在册）、入职年限分布

**怎么用**：
- **人数曲线**：不同时间两次查询对比，得出扩张/收缩趋势。也可通过网页快照（web.archive.org）回溯历史
- **结构判断**：投顾占比高=财富管理转型中；经纪人占比高=传统通道模式
- **流动率**：同名人员间隔半年对比，进出频繁=团队不稳定
- **负责人任职时长**：从业登记可追溯其履历（前任网点、任职年限），判断是"老将坐镇"还是"新官上任"

**注意**：人员挂靠与实际在岗可能有差异，数据作为趋势参考而非精确值。

## 2. 龙虎榜数据（P1）

**数据源**：
- 东方财富/同花顺龙虎榜营业部排行（按营业部检索历史上榜记录）
- AKShare：`ak.stock_lhb_*` 系列接口

**查什么**：
- 该营业部近1-3年上榜次数、净买入方向、金额量级
- 联动席位：经常与哪些知名游资席位/机构席位同现
- 行业排名位置（如年度龙虎榜营业部百强）

**解读框架**：
- 高频+游资联动=交易型客群为主，散户活跃
- 偶发+机构专用席位联动=有机构客户资源
- 从不上榜=非游资聚集地（正常现象，不代表差）
- 排名跃升案例（如从300名外进百强）通常伴随网点转型或负责人更换，是纵轴重要事件

## 3. 工商与监管信息（P1）

**数据源**：
- 企查查/天眼查/爱企查：营业部工商登记（成立日期、地址变更、负责人变更、更名记录）
- 证监会及地方证监局官网：行政监管措施、行政处罚（按机构名称检索）
- 中国裁判文书网/执行信息：涉及该网点的诉讼纠纷

**解读要点**：
- 成立时间>15年=存量客户厚；<3年=爬坡期
- 地址变更频繁（3年内2次以上）=经营不稳定信号
- 负责人变更=打法可能切换，结合变更前后信号对比
- 罚单性质分级：适当性/内控类=行业普遍；欺诈/挪用类=恶性

## 4. 招聘信号（P2）

**数据源**：猎聘/前程无忧/BOSS直聘/券商官网招聘页，检索"券商名+城市名"

**解读框架**：
- 招投资顾问/财富顾问=转型加码
- 招经纪人/客户经理（大量）=冲量扩张
- 招机构业务岗=向机构化转型
- 长期零招聘=维持或收缩
- 同一岗位反复挂出=留不住人

## 5. 线上痕迹（P2）

**数据源**：
- 微信公众号（券商总部号+网点自有号）：活动频率、内容类型（投教/产品/沙龙预告）
- 百度地图/高德地图POI：地址核实、街景（写字楼档次）、用户评价
- 雪球/抖音/小红书：该网点从业者的自媒体账号（优秀投顾常有个人IP）

**解读**：公众号月更以上+线下沙龙预告频繁=主动经营；公众号停更一年以上=活力存疑。网点有员工运营个人IP=团队里有能人。

## 6. 总部信息（P0，纵轴总部层）

**数据源**：
- 券商年报（巨潮资讯/官网）：经纪业务净收入、代销金融产品收入、托管市值、股基市占率、财富管理条线表述
- 公司公告：组织架构调整、增资、高管变动
- 行业排名：证券业协会年度经营数据排名（经纪业务净收入排名、代销收入排名）
- AKShare/Tushare 获取财务数据，参考 china-market-data skill 的接口规范

**查什么**：总部战略阶段（扩张/转型/收缩）、财富管理转型力度、对该区域（分公司）的资源倾斜证据（新设旗舰网点、品牌活动落地城市）。

## 7. 交叉印证技巧

- **三角验证**：同一结论至少两个独立信号源支撑（例："该网点在扩张"=招聘信号+人数曲线同向）
- **快照回溯**：web.archive.org 查官网网点介绍页的历史版本，获取历史人员/地址信息
- **地图反查**：从地址反查同写字楼/同商圈的其他金融机构，构建横轴同商圈坐标
- **负面检索**：组合关键词"网点名+投诉""券商名+营业部+处罚""网点名+纠纷"做负面信息排查
- **区分同名**：部分营业部更名过，检索时带上曾用名；工商信息里的名称沿革是权威依据
