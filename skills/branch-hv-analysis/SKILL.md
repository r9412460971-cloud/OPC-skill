# 券商营业部横纵分析

> 方法论定位：继承 hv-analysis 的双轴框架，但针对"营业部几乎没有公开叙事"这一事实做了特化——公司分析靠公开信息还原，营业部分析靠**可观测信号拼图**。纵轴追事件链，横轴建坐标系，结论落到"这个网点靠什么活着、在向哪走、对你意味着什么"。

## 核心认知（先读这个）

营业部不是独立法人，而是三层嵌套结构：**总部禀赋 → 区域生态 → 网点本身**。单独看网点会失真，三层必须同时进入分析。

营业部的收入公式：经纪佣金（交易量×佣金率）+ 两融利差 + 产品销售中收 + 机构业务分仓。所有信号最终都要映射回这四个收入源做判断。

## 数据可得性三级标注（强制执行）

营业部分析的最大陷阱是"脑补"。每个数据点和结论必须标注三级之一：

- **【可查】**：公开数据可验证，注明来源
- **【需输入】**：公开渠道无法获得，提示用户补充（如内部排名、实际考核指标）
- **【推断】**：基于代理指标的推测，必须写明推断依据（例：【推断】该网点偏交易型——依据：龙虎榜月均上榜3次且以游资席位联动为主）

宁可标注"信息暂缺"，绝不编造。

## 工作流程

### 第0步：明确场景与输出档位

先确认使用者身份和用途，决定报告的侧重点与输出形态：

| 场景 | 使用者 | 核心问题 | 默认输出 |
|---|---|---|---|
| 渠道拜访 | 基金公司/券商渠道经理 | 这个网点值不值得跑、找谁、带什么 | 一页纸速览卡 |
| 网点诊断 | 总部管理者/营业部总经理 | 我的网点在坐标系里什么位置、短板在哪 | 深度报告PDF |
| 竞对摸排 | 券商/财富机构 | 对方在抢什么客群、打法是什么 | 深度报告PDF |
| 求职尽调 | 求职者 | 这个平台有没有前途、团队稳不稳 | 一页纸速览卡 |

场景详细指引与各场景输出模板见 `references/scenarios.md`。用户未说明身份时，默认按"网点诊断"输出综合版深度报告，并在开头注明可按其他场景重切。

### 第1步：信号采集

按优先级采集可观测信号，全部数据源与具体查询方法见 `references/data-sources.md`：

1. **证券业协会从业人员公示**（最重要）：该网点执业人数、投顾资质人数、一般从业人数；多时点对比得出**人数曲线与流动率**——这是营业部景气度最硬的代理指标
2. **龙虎榜记录**：上榜频率、买入卖出结构、联动席位属性（游资/机构/北向）——判断客群属性
3. **工商与监管信息**：成立时间、迁址/更名记录、负责人变更、监管处罚、裁判文书
4. **招聘信号**：在招岗位数量与类型（扩投顾=转型中、扩经纪人=冲量、不招人=收缩）
5. **线上痕迹**：公众号更新频率与内容、地图POI评价、社群活动
6. **总部信息**：所属券商年报中的经纪业务数据、财富管理战略、对该区域的资源倾斜表述

采集原则：多次搜索、交叉印证；一手来源（协会公示、交易所龙虎榜、监管罚单）优先于聚合平台。

### 第2步：纵轴——双层事件链

**网点层生命史**：成立 → 迁址/更名 → 负责人更替 → 处罚/纠纷 → 龙虎榜进出 → 人员规模变化。每个事件追问"这意味着什么"（迁址到更高档写字楼=升级还是撑面子？人员三年减半=收缩还是转型投顾化？）。

**总部层战略周期**：所属券商当前处于什么战略阶段（扩张/转型/收缩/求生），财富管理转型力度如何，这决定了网点能拿到多少资源。网点命运由总部决定，这一层不可省略。

### 第3步：横轴——三层坐标系

- **同商圈竞对**：3公里内主要券商网点对比（人员规模、客群属性、活跃度），回答"它在抢谁的生意、被谁抢"
- **同券商内部坐标**：该网点在自家体系内的相对位置（旗舰/普通/卫星），参考同券商公开标杆网点
- **同类基准**：同城市能级、同开业年限网点的行业一般水平，回答"好于还是差于及格线"

### 第4步：横纵交汇——输出三个判断

1. **靠什么活着**：该网点当前收入结构的最可能形态（散户型交易/产品销售型/机构型/两融型），给出推断依据
2. **在向哪走**：结合总部战略与网点信号，给出发展推演（扩张/转型/维持/收缩），并给出三个剧本（最可能/最危险/最乐观）
3. **对你意味着什么**：按第0步识别的场景给出可执行建议（拜访策略/诊断结论/竞对应对/求职建议）

### 第5步：输出

- **速览卡**（1页）：网点画像一句话 + 关键信号表 + 三个判断 + 行动建议。Markdown直接交付
- **深度报告**（PDF）：完整四章结构（一句话画像 → 纵轴双层事件链 → 横轴三层坐标 → 交汇判断与建议），用 `scripts/md_to_pdf_playwright.py` 渲染：
  ```bash
  python scripts/md_to_pdf_playwright.py input.md output.pdf --title "XX证券XX营业部分析" --author "R9（资产配置研习社）"
  ```

## 常见坑（写作时自检）

- **龙虎榜缺失 ≠ 不活跃**：绝大多数营业部从不上榜，缺失本身只是说明非游资聚集地
- **人数少 ≠ 差**：财富管理转型期网点主动裁经纪人、增投顾是健康信号，要看结构变化而非总量
- **处罚记录要看性质**：适当性管理类罚单在行业普遍存在，挪用资金类才是恶性
- **别把总部光环当网点实力**：头部券商的尾部网点可能还不如区域券商的旗舰网点
- **地址变更频率**是被低估的信号：频繁迁址通常意味着经营不稳定
- 所有关键结论回检：有没有标注三级可得性？推断是否写了依据？

## 质检清单

- [ ] 三层嵌套（总部/区域/网点）都覆盖了吗？
- [ ] 纵轴是事件链解读而不是年表罗列？
- [ ] 横轴三层坐标各至少有一个对比对象？
- [ ] 每个数据点标注了【可查】/【需输入】/【推断】？
- [ ] "靠什么活着"的收入结构判断有信号支撑？
- [ ] 三个剧本（最可能/最危险/最乐观）都有逻辑支撑？
- [ ] 结尾建议与第0步识别的场景对齐？
- [ ] 搜不到的信息诚实标注"暂缺"，没有编造？
