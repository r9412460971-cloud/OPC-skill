# 进度追踪、错题本与家长报告格式

## 一、文件格式

### progress.json

按"科目 → 章节/模块 → 知识点"三级记录掌握度（0=未学，1=听过不懂，2=能模仿，3=独立做对，4=熟练，5=能讲给别人听）。

```json
{
  "learner": "昵称",
  "updated": "2026-09-05",
  "subjects": {
    "math": {
      "六上·第一章·数的整除": {
        "分解素因数": {"level": 3, "correct": 8, "wrong": 2, "last": "2026-09-01"},
        "最大公因数与最小公倍数": {"level": 2, "correct": 3, "wrong": 3, "last": "2026-09-03"}
      }
    },
    "chinese": {},
    "english": {}
  },
  "weak_top3": ["数学·最小公倍数应用", "英语·一般过去时不规则动词", "语文·文言文实词"],
  "streak_days": 5
}
```

- 章节名必须与 `references/chinese.md` / `math.md` / `english.md` 中的教材章节地图一致。
- 每次会话后更新：改 `level`、`correct/wrong` 计数、`last` 日期；重算 `weak_top3`（取 level≤2 且 wrong 最多者）。

### sessions.jsonl

每次会话一行 JSON：

```json
{"date":"2026-09-05","time":"19:00","duration_min":35,"mode":"陪写作业","subjects":["math"],"topics":["分数除法"],"summary":"分数除法法则能背但应用题列式弱","homework_assigned":["错题本2道回访","课本P32练一练"],"mood_flag":false,"escalate":false}
```

- `mode` 取值：摸底 / 陪写作业 / 讲错题 / 预习 / 复习 / 出题练 / 考前冲刺 / 默写听写。
- `mood_flag` / `escalate` 规则见 `references/safety.md`。

### error-log.md（错题本）

按科目分区，每道错题一条：

```markdown
## 数学
### M-012 | 2026-09-03 | 六上·第二章·分数 | 待复习:2026-09-10
- **题目**：（原题或脱敏后的题干）
- **错因分类**：概念不清 / 计算失误 / 审题偏差 / 方法不会 / 粗心
- **学生当时思路**：……
- **正确关键**：除以一个数=乘它的倒数；应用题先找单位"1"
- **复习记录**：[1天✔] [3天✔] [7天·到期未做] [30天]
```

- 编号规则：语文 Y-xxx、数学 S-xxx、英语 E-xxx（取拼音首字母，避免和编号 M 混淆，用 S 不用 M）。
- **复习节奏**：新错题录入后按 1天/3天/7天/30天 排期，写入"待复习"日期；每次会话开场先扫描到期项，回访做对就打勾，做错则重排期并把 level 降 1。
- 连续 2 次回访全对的错题，可标记"已消化"，归档到 `error-log.md` 底部"已消化"区。

## 二、家长报告（周报）

### 触发

按 `profile.md` 里家长设定的频率（默认每周一次，建议周日晚）生成 `reports/YYYY-Www.md`。

### 模板

```markdown
# 学习周报 · {昵称} · 2026年第37周（09.07-09.13）

## 本周概览
- 学习 4 次，共 135 分钟；连续学习 5 天
- 数学 2 次 / 语文 1 次 / 英语 1 次

## 本周亮点（具体、可感知）
- 数学：分数应用题从"列式靠猜"到能主动找单位"1"，同类题 5 道对 4
- 英语：一般过去时 20 个不规则动词默写全对

## 需要关注
- 数学·最小公倍数应用仍是薄弱点（本周错 3 题），下周计划用生活场景题巩固
- 单次学习偏长（周三 50 分钟），建议中途提醒休息

## 错题与复习
- 新增错题 4 道（数 2 / 英 1 / 语 1），已按节奏排复习
- 到期回访 6 道，5 道通过，1 道（S-009）需继续跟进

## 下周计划
1. 数学：完成第二章分数单元复习，做 1 次 15 分钟小测
2. 语文：预习《文言文二则》，重点实词 5 个
3. 英语：Module 2 词汇滚动默写 2 次

## 给家长的一句话
本周孩子学习状态稳定，分数应用题进步明显，建议多肯定"会找单位1"这个方法层面的进步。
```

### 写报告原则

- 用数据说话：次数、时长、对错数，全部来自 `sessions.jsonl` 和 `progress.json`，不虚构。
- 亮点必须具体到知识点和方法，不写"表现不错"这种空话。
- 问题永远配解决方案（"需要关注"里的每条都要有对应动作）。
- `mood_flag` 或 `escalate` 为 true 的会话，在"需要关注"首条如实、中性、不贴标签地说明。
