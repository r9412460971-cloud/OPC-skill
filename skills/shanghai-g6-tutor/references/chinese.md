## 二、四大板块教学策略

### 1. 文言文（六上起新增，中考根基）
- **方法**：读顺（断句）→ 译通（逐字落实）→ 悟理（寓意/启示）。
- **实词积累**：每课 5-8 个重点实词进"文言词卡"，如《学弈》：弈、诲、惟、俱、弗；《两小儿辩日》：辩斗、以、去、及、汤、决、孰、汝。
- 要求会背、会默、会逐句翻译；翻译遵循"留删换调补"原则，先让学生逐字猜，再对照。
- 高频考点：重点实词解释、句子翻译、寓意理解、断句。

### 2. 现代文阅读（拉分主战场）
教学生"题型 → 答题公式"意识，但不死记公式：
- **概括主要内容**：谁 + 在什么情况下 + 做了什么 + 结果怎样。
- **赏析句子**：手法（比喻/拟人/排比/环境描写…）+ 写出了什么 + 表达了什么情感。
- **环境描写作用**：交代背景/渲染气氛/烘托心情/推动情节/为下文铺垫。
- **人物形象**：从具体事件和细节（语言、动作、神态）找依据，"观点+原文证据"两段式作答。
- 训练法：先口头说完整再落笔；答完对照"有没有结合原文"自查。

### 3. 作文（六年级以记叙文为主）
- 六年级习作重点：围绕中心意思写（六上五单元）、把情感真实具体地表达出来（六下三单元）。
- **辅导法**：只帮搭骨架（审题→选材→列提纲），正文学生自己写；写完后用"提问式批改"："这段如果加一个你当时心跳的细节，读者会不会更紧张？"
- 常见问题对策：
  - 流水账 → 练"详写一件事，略写其余"
  - 没细节 → 五感描写练习（看到/听到/闻到/摸到/心里）
  - 开头难 → 提供 3 种开头方式（场景式/悬念式/引用式）让学生选

### 4. 基础知识
- 字词：每课生字词滚动默写，易错字进错字清单。
- 成语、病句（搭配不当/成分残缺/语序不当/重复累赘）、标点、修辞为常规考点。

## 三、常见易错点（预初期高发）

- 文言文翻译漏字、意译过度；实词"以、之、其"等多义词混淆。
- 阅读题"答不全"：只答手法不答情感，或不结合原文。
- 作文详略失衡、结尾强行拔高喊口号。
- 古诗词默写同音字错（如"浪淘风簸"的"簸"）。

## 四、出题参考

- 基础题：看拼音写词语、选择恰当成语、病句修改。
- 文言文：给出课内篇目段落，考 2 个实词 + 1 句翻译 + 寓意。
- 阅读：150-300 字记叙文片段 + 3 题（概括/赏析/人物形象）。
