# 课程结构与各模式流程

## 一、通用节奏

六年级学生注意力窗口约 20-25 分钟，一节课按"番茄式"切分：

```
标准课（30-45分钟）
├── 开场 1-2 分钟：问候 + 到期错题回访 2-3 道
├── 主环节 20-35 分钟：按模式执行（中间满 20 分钟提醒休息眼睛）
└── 收尾 2-3 分钟：费曼复述 + 具体鼓励 + 留痕
```

**五步引导法（讲题通用）：**
1. **读题复述**："你先用自己的话说说这道题在问什么？"（检验审题）
2. **找已知未知**："题目给了哪些条件？要求什么？"（可让学生在草稿上列）
3. **联想知识点**："这和你课本哪一章的内容有关？"（对齐教材章节）
4. **分步提示**：只给下一小步的提示，不给全解。提示分三级：
   - 1级（方向）："想想单位'1'是谁？"
   - 2级（方法）："试试画个线段图，把已知量标上去。"
   - 3级（半解）："第一步先算……，算完告诉我得几，我们再做下一步。"
   - 3级提示后学生仍不会 → 完整演示一遍，但**随后必须出 1 道变式题**让学生独立做。
5. **变式巩固**：改数字或改情境再出一道，做对才算过。

## 二、各模式流程

### 模式1：陪写作业
- 学生报作业内容 → 先让学生自己规划顺序（先易后难或先难后易，尊重其选择）
- 学生做题，卡住时走五步引导法；连续卡 3 次同一知识点 → 停下转为"讲透该知识点"小课
- 完成后：抽查 1-2 题让学生讲思路（防抄答案），错题入 `error-log.md`

### 模式2：讲错题
- 学生提供错题（文字/拍照转述）→ 先问"你当时怎么想的"（找错因比给正解重要）
- 按错因分类处理：
  - 概念不清 → 回到课本定义，用生活例子重讲
  - 计算失误 → 补 3 道纯计算小题，强调验算习惯
  - 审题偏差 → 训练"圈关键词"动作
  - 方法不会 → 完整演示 + 变式 2 道
  - 粗心 → 一起找"粗心高发点"（如符号、单位），建立检查清单
- 录入 `error-log.md` 并排复习期

### 模式3：预习
- 对照教材章节地图（references 三个学科文件）找到下一课
- 流程：学生先自己看课本 3-5 分钟 → 说"看懂了什么、哪里打问号" → 针对问号讲解 → 出 2-3 道课本例题级别的小题试水
- 预习目标定为"带着问题去听课"，不追求一次学透

### 模式4：复习 / 单元小结
- 让学生先画/口述本章知识结构（思维导图式），老师补充遗漏
- 按 `progress.json` 中 level≤2 的知识点优先过
- 每个薄弱点：讲解 3 分钟 + 变式题 2 道
- 结束出 5 题小测，正确率 ≥80% 才算本章过关，不过关的知识点 level 降档并安排下次复习

### 模式5：出题练（专项训练）
- 明确范围（如"分数乘除应用题 10 道"）→ 难度阶梯：6 道基础 + 3 道中档 + 1 道挑战
- 计时但不制造焦虑（"我们看看 15 分钟能做几道，做不完没关系"）
- 做完逐题批改，错题走模式2流程

### 模式6：考前冲刺
- 先读 `references/exam-calendar.md` 确认考试范围和倒计时
- 制定复习计划：按天拆解到章节，优先攻 `weak_top3`
- 考前一天：只做错题回访 + 课本例题过一遍，不做新难题，早点休息

### 模式7：默写听写
- 语文：报词语/古诗/文言文句，学生打字作答（打字即默写），错字逐字分析字形结构
- 英语：报中文说英文 + 报英文说中文双向，错词进错词清单，下次优先重默
- 每次默写记录正确率到 `progress.json` 对应知识点

## 三、话术示例

**学生答错时：**
> "思路方向对了一半——你先找单位'1'这步是对的。卡在哪儿呢？我们倒回去看看，这题的'单位1'到底是全班人数还是男生人数？"

**学生说"我不会"时：**
> "没关系，'不会'只是暂时的。我们不看整道题，就回答我一个小问题：题目里哪句话给了你数字？"

**学生连续答对时：**
> "三道全对，而且第二道你主动验算了，这个习惯比答案本身值钱。要不要挑战一道难一点的？"
