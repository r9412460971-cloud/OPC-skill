# 英语（牛津上海版 / 新世纪版 · 六年级）

上海初中英语教材主要有三版：**牛津上海版**（老版）、**上教版《英语》2024 新课标版**（2024 年秋起新初一启用）、**新世纪版**（部分学校）。**建档时必须用课本照片确认实际版本**，以该校教材的单元目录和词汇表为准。本文件提供通用的语法体系和教学法。

## 一、六年级语法地图（两版通用）

### 六年级上
| 语法点 | 要点 | 高频易错 |
|---|---|---|
| be 动词与实义动词区分 | 一般现在时中 be 与 do/does 不混用 | He ~~is~~ like apples 类错误 |
| 一般现在时三单 | 动词 +s/es；否定疑问用 does | 三单漏 s；does 后动词忘还原 |
| 现在进行时 | be + doing；标志词 now/look/listen | 漏 be 动词；双写规则（run→running） |
| 名词单复数 | 规则/不规则（child→children）；不可数名词 | 不可数名词误加 s；a/an 选择 |
| 代词 | 人称、物主（形容词性/名词性）、反身初步 | his/her 混淆；mine/my 混用 |
| there be 句型 | 就近原则 | there have 错误；单复数判断 |
| 情态动词 can/must | 后接动词原形；含义区别 | can 后加 to；must 否定含义误解（mustn't=禁止） |

### 六年级下
| 语法点 | 要点 | 高频易错 |
|---|---|---|
| 一般过去时 | 规则动词 +ed；常见不规则动词（go-went, have-had, see-saw, buy-bought…） | did 后动词忘还原；不规则变形记错 |
| 一般将来时 | will / be going to | 两者混用场景；be going to 漏 be |
| 形容词比较级最高级 | 规则变化 + 不规则（good-better-best） | more + 单音节词；than 前后可比性 |
| 频率副词与 How often | always/usually/often/sometimes/never 位置 | 副词放句尾错误 |
| 介词 | 时间（in/on/at）、地点方位 | in the morning vs on Monday morning |
| 现在完成时（启蒙） | have/has + 过去分词，仅校内涉及层面 | 与一般过去时混淆 |

## 二、四大板块教学策略

### 1. 词汇（根基中的根基）
- **来源**：以孩子课本每单元 Word list 为准，不超纲拔高。
- **滚动默写法**：新学 10-15 个词 + 旧词回滚（错词优先），双向互译（中→英、英→中）。
- 错词进 `error-log.md` 英语区，按 1/3/7/30 天节奏重默。
- 记词方法教三招：音节切分（rest-au-rant）、词根词缀启蒙（un-, -er, -ly）、放进课文原句记。

### 2. 语法
- 讲解顺序：情境例句引入 → 让学生自己观察规律 → 总结规则 → 造句应用。
- 时态对比教学：学完一般过去时后，必须与一般现在时对比练习（时间状语是题眼：every day vs yesterday）。
- 每个语法点配"错题回炉"：从 `error-log.md` 调同类错题重做。

### 3. 阅读与完形
- 课内课文：要求朗读（纠发音）、复述（3-5 句话概括）、重点句型仿写。
- 应试技巧启蒙：先读题再读文；细节题回原文找证据句；猜词题看上下文。

### 4. 听说与写作
- 听说：课文句型角色扮演（问路、购物、点餐等教材情境）；鼓励学生整句输出，不纠每一个小错（先流利后准确）。
- 写作：六年级以 40-60 词小短文为主（My friend / My weekend / A healthy diet）。教法与语文作文一致：给结构（开头-主体-结尾三段式）和句型支架（I often… / He likes… because…），学生自己写，写后只改"影响理解的错误"和"本次目标的语法点"，不全篇改红。

## 三、上海校内常见题型

选择题、语音/词汇题、句型转换（改否定/疑问/对划线部分提问）、完形填空、阅读理解（选择+判断）、首字母填空（下册渐多）、小作文。

- **句型转换**是六年级失分重灾区，专项练：陈述→否定→一般疑问→特殊疑问 四步变。
- **首字母填空**：教"先通读判词性，再据上下文填词，最后复查语法形式"三步法。

## 四、默写听写模式细则

1. 报中文 → 学生打英文（考拼写）；报英文 → 学生打中文（考识记）。比例约 2:1。
2. 每批 10-15 个，默完即时批改，错词当场拼读 2 遍 + 造句 1 个。
3. 记录：`{date, total, correct, wrong_words[]}` 写入 sessions.jsonl，错词入错题本。
