## 二、工作流程

### Step 1: 客户背景梳理

- 客户基本信息、家庭结构、职业变化
- 可投资资产、流动资产变化
- 投资目标优先级是否变化
- 风险承受能力是否变化
- 流动性需求变化
- 上次会议待办完成情况

### Step 2: 组合业绩回顾

| 指标 | 本季度 | 本年度 | 成立以来/定制周期 |
|------|--------|--------|----------------|
| 组合收益率 | | | |
| 基准收益率 | | | |
| 超额收益 | | | |
| 最大回撤 | | | |
| 年化波动率 | | | |

> 基准采用客户 IPS 中约定的基准，如：中证800*50% + 中债总财富*30% + 黄金*10% + 货币*10%

### Step 3: 业绩归因

- **Top 3 贡献者**：哪些产品/资产类别贡献最大
- **Top 3 拖累者**：哪些产品/资产类别拖累业绩
- **配置效应**：资产配置偏离带来的贡献
- **选择效应**：产品选择带来的贡献

### Step 4: 配置回顾

| 资产类别 | 目标权重 | 当前权重 | 偏离 | 行动 |
|---------|---------|---------|------|------|
| 权益类 | | | | |
| 固收类 | | | | |
| 另类 | | | | |
| 现金/货币 | | | | |

### Step 5: 会议议程生成

1. **市场回顾**（3-5分钟）：本季度股/债/商品/外汇市场主要变化
2. **组合业绩**（5-8分钟）：收益、回撤、归因、与基准对比
3. **配置检视**（5分钟）：是否需要再平衡
4. **目标与约束回顾**（5-10分钟）：
   - 家庭/企业资金需求变化
   - 税务情况变化
   - 传承规划进展
   - 保险/信托安排
5. **下一步行动**（5分钟）：明确待办、负责人、时间节点

### Step 6: 主动建议

- 再平衡建议（如漂移超阈值）
- 新增资金配置方案
- 私募开放期操作提醒
- 税务优化机会
- 传承/信托安排建议
- 保险缺口检视

### Step 7: 输出

- 一页式会议准备纪要（Markdown / PDF）
- 会议议程
- 谈话要点
- 行动项清单

## 三、高净值客户特殊议题

### 税务优化

- 公募基金分红方式选择（现金分红 vs 红利再投资）
- 私募基金收益核算与税负
- 保险年金税收递延优势
- 家族信托税务架构

### 财富传承

- 保单 + 信托架构检视
- 受益人安排
- 家企资产隔离
- 下一代财商教育

### 流动性管理

- 企业经营资金需求
- 大额支出计划（购房、教育、医疗）
- 应急准备金 adequacy
