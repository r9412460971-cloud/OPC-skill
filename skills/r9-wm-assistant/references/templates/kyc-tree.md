# KYC 逻辑树（按客群类型）

> 源自辅导文件"客群 KYC 要求"：白领 / 中小企业主 / 家庭主妇 / 支行其他目标客群。使用时先选定客群，按树状路径提问，边问边填客户档案。

## 通用主干（所有客群必经）
```
资金从哪里来（收入/经营/拆迁/继承） 
  → 钱现在放在哪（存款/理财/他行/三方）
    → 短期的钱 / 长期不用的钱 各有多少
      → 未来大额支出计划（买房/教育/养老/生意周转）
        → 亏过什么钱 / 赚过什么钱（投资经验与伤疤）
          → 家里谁管钱、谁拍板
            → 风险测评确认
```

## 白领
- 主线：工资结余 → 强制储蓄 → 基金定投 + 年金补充养老
- 关键问句：
  - "每个月工资到手，扣掉房贷和开销，还能剩下多少？"
  - "公司有没有企业年金？社保养老替代率您算过吗？"
  - "孩子教育金打算怎么准备，从几岁开始用？"
- 典型痛点：没时间理财、定投坚持不住、年终奖一把梭

## 中小企业主
- 主线：公私资金混同 → 隔离与流动性 → 保险（身价/传承）+ 灵活申赎产品
- 关键问句：
  - "生意上的钱和家里的钱，现在是分开的吗？"
  - "如果生意上要临时用一笔钱，家里的资产哪些能动？"
  - "孩子以后接不接班？资产怎么给到他最稳妥？"
- 典型痛点：资金进出不规律、怕锁死流动性、关注税务与传承

## 家庭主妇
- 主线：家庭财务安全感 → 子女教育 → 稳健收益 + 教育金保险
- 关键问句：
  - "家里的钱主要是谁在打理？每个月家用之外能结余多少？"
  - "孩子以后上学，打算国内还是出国？大概要准备多少钱？"
  - "如果家里收入突然中断，现在的积蓄能撑多久？"
- 典型痛点：怕亏、被高收益骗过、决策需要和家人商量

## 使用规则
1. 每次面谈只走一条主线，不贪多
2. 每问出一个关键信息，当场记入客户档案
3. 逻辑树在使用过程中持续完善——发现好用的问句就补进对应分支
