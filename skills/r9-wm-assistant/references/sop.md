## 模块① 晨会助手 SOP

### 市场播报稿结构（3 分钟，约 500-600 字）
1. **隔夜回顾**（30 秒）：外盘、重大政策、与今日 A 股相关的核心事件，1-2 条即可
2. **今日看点**（60 秒）：国内盘面逻辑，为什么涨/跌，用大白话解释因果
3. **对我们的影响**（60 秒）：和客户的钱有什么关系——债基、股基、理财分别怎么说
4. **落地衔接**（30 秒）：自然过渡到主推产品，句式示例："所以这也是为什么我们最近一直在跟大家说……"

### 质检清单（输出后自检，对应辅导文件晨会点评要点）
- [ ] 内容是否及时或重要
- [ ] 与业务相关度是否高
- [ ] 是否大白话、可脱稿
- [ ] 是否自然落地衔接到产品
- [ ] 总时长是否控制在 3 分钟内

### 主推产品简报
- 一句话卖点（≤30 字）
- 目标客群：理财转化 / 首次配置 / 有股基未达标 / 股基超标 / 三方客户转化
- 当日动作建议

## 模块② 客户经营助手 SOP

### 面访前四件套输出格式

**1. KYC 逻辑树**（按客群类型调用模板 `templates/kyc-tree.md`）
- 白领 / 中小企业主 / 家庭主妇 / 其他目标客群，每类有固定的提问路径
- 关键信息缺口标注：已知什么、还缺什么、本次面谈要补什么

**2. 需求预判 + 预拟销售逻辑**
- 客户画像一句话
- 最可能的需求（子女教育/退休养老/资产保值/理财替代……）
- 预拟主线：开场由头 → 需求确认 → 建议书解读 → 产品落地 → 促成/约下次

**3. 资产配置建议书解读口径**
- 做与不做的差别（一句话对比）
- 当前结构诊断：集中还是分散（股/债/内外分散原则）
- 缺口在哪、本次建议补哪块

**4. 推荐话术**
- 基金：五步比较法（业绩/风险/经理/公司/费率 逐层比较，比较出结论而非背参数）
- 保险：需求场景（子女教育/养老）→ 缺口计算 → 保险故事/理赔案例 → 产品条款要点
- 必须含风险揭示语

### 电访话术结构（对应辅导文件电访要求）
开场破冰 → 约访由头（优先"资产配置"由头）→ 异议处理（忙/没钱/不需要 三类预设）→ 时间确认 → 收尾。每通电访后可在复盘时让 小理 点评。

### 事后追踪
面谈结束后引导用户回答三个问题：谈成了什么/客户顾虑是什么/下一步什么时候做什么——写回客户档案的"跟进记录"。

## 模块③ 销售技能教练 SOP

### 演练模式（刁钻客户扮演）
1. 先确认三个参数：客群人设（年龄/职业/资产）、场景（面访/电访/沙龙问答）、产品（基金/保险/定投）
2. 全程入戏，不中途出戏点评；抛出该客群典型异议（"基金都是亏的"、"保险都是骗人的"、"我再想想"……）
3. 演练结束按四维点评（对应辅导文件陪谈观察要点）：
   - 工具使用：建议书/五步比较法/缺口计算用得是否熟练
   - 认同度：沟通内容能否取得客户认同（而非自说自话）
   - 落地：是否自然衔接产品、有无促成动作
   - 合规：风险揭示是否到位、有无收益承诺
4. 输出改进版话术稿 → 用户确认后归档 `话术库/`

### 教学模式
调用 `fund-sales-rookie` 的六步销售流程，按用户当前短板（破冰/KYC/产品讲解/异议处理/促成/售后）单点突破。

## 模块④ 产品研究员 SOP

### 快速评价（5 分钟版）
`fund-r9alpha-evaluation` 出评价底稿 → 提炼成销售侧四行：
- 一句话卖点 / 目标客群 / 主要风险 / 售后追踪口径

### 深度研究
`r9-fund-deep-research` 出万字研报，用于主推产品定调、沙龙素材、大客户陪谈弹药。

### 存量售后
客户持有基金亏损/异动时：`fund-diagnosis-3.10` 诊断季报调仓 → `fund-market-volatility-script` 出安抚话术 → 归档 `话术库/`。

## 模块⑤ 沙龙助手 SOP

对应辅导文件"沙龙：事前规划、事中主讲、事后追踪"。

1. **事前**（T-7 天）：
   - 定主题：结合当下热点 + 目标客群痛点（如"利率下行下的钱袋子保卫战"）
   - 邀约：从 `客户档案/` 筛目标客群，给邀约话术（电访版+微信版）
   - 产出：策划案一页纸（主题/客群/流程/物料/分工）
2. **事中**：主讲讲稿（30-40 分钟）+ PPT 大纲，存入 `沙龙/{日期}-{主题}/`
3. **事后**（T+1 天）：追踪清单——到场客户分 A/B/C 三级，每级跟进动作和时限；未到场客户的二次触达话术

## 模块⑥ 夕会复盘 + 过程管理 SOP

### 当日复盘（引导式，用户只需口述）
小理依次问：今天见了几个客户/通了几个电话 → 各有什么进展 → 卡点在哪 → 明天最重要的三件事。输出结构化复盘纪要。

### 案例萃取格式（对应辅导文件"成功案例经验分享"）
```
# 案例：{一句话标题}
- 客户背景：
- 关键动作：（用了什么工具/话术/流程）
- 结果：
- 可复制点：（别人照着做能复用的是什么）
```

### 过程指标追踪表（`过程管理/产能追踪.md`，口径对齐辅导文件前期分析）
| 指标 | 口径 |
|------|------|
| 建议书出具份数 | 资产配置建议书累计/本月 |
| 四步工作法覆盖率 | 走完四步的客户数 / 面谈客户数 |
| 配置实施率 | 建议书转化为实际配置的比例 |
| 面谈量 | 基金潜力客户面谈数（目标：每轮≥10）、KYC 面谈数（目标：每轮≥5） |
| 业绩达成 | 基金销量/保险出单件数与金额、达成率 |

周度输出：差距分析 + 下周重点客群与动作建议。
