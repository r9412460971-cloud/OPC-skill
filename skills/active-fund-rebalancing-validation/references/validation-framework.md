## 纵向分析框架

### 1. 8 季度十大重仓时间轴

构建一张表，行是股票，列是季度，单元格为占净值比。例如：

```markdown
| 股票 | 2024Q1 | 2024Q2 | 2024Q3 | 2024Q4 | 2025Q1 | 2025Q2 | 2025Q3 | 2025Q4 |
|------|--------|--------|--------|--------|--------|--------|--------|--------|
| 润丰股份 | 8.5% | 8.2% | 8.8% | 8.1% | 7.9% | 8.3% | 8.0% | 7.8% |
| 宁德时代 | - | 2.1% | 3.5% | 4.2% | 5.1% | 4.8% | 3.2% | - |
```

### 2. 核心持仓识别

按连续持有季度数划分：

| 持续季度 | 标签 | 含义 |
|---------|------|------|
| ≥6 季度 | 核心持仓 / 压舱石 | 基金经理长期信念仓位 |
| 4-5 季度 | 稳定持仓 | 阶段性看好 |
| 2-3 季度 | 波段操作 | 灵活调整 |
| 1 季度 | 试探性仓位 | 短期尝试 |

### 3. 调仓节奏分类

每季度新增 + 退出股票数量合计：

| 调仓幅度 | 股票变动数 | 说明 |
|:-------:|:---------:|------|
| 微调 | 1 只 | 观望状态，持股信心强 |
| 调整 | 2-3 只 | 常规调仓，优化结构 |
| 大调 | ≥4 只 | 重大转向，策略变化 |

### 4. 关键调仓事件识别

以下事件需在报告中重点展开：

- **新建即 TOP5**：本季新买入即进入前五大重仓
- **清仓高占比**：上期占比 ≥4% 的标的被清出前十
- **单季行业漂移**：某行业配置占比变化 ≥5pp
- **第一大重仓变更**：核心信念仓位切换
- **集中度骤变**：前十大占比单季变化 ≥10pp

### 5. 行业配置演变

将十大重仓映射到板块：

| 板块 | 包含行业 |
|------|---------|
| 周期 | 化工、有色、钢铁、煤炭、建材 |
| 防御 | 电力、银行、公用事业、高速 |
| 成长 | 医药、新能源、半导体、TMT |
| 消费 | 食品饮料、家电、农林牧渔 |
| 金融 | 银行、保险、券商 |
| 制造 | 机械、汽车、军工 |

追踪每个板块过去 8 个季度的占比变化，识别主线迁移。

## 横向分析框架

### 1. 同类基金选取

- 同策略分类（偏股混合 / 灵活配置 / 普通股票型等）
- 同基金公司或同基金经理风格
- 数量：3-5 只

### 2. 重叠分析

构建「标的 × 基金」矩阵：

```markdown
| 标的 | 本基金 | 基金A | 基金B | 基金C | 基金D | 共识度 |
|------|--------|-------|-------|-------|-------|--------|
| 茅台 | 8.5% | 7.2% | - | 6.1% | 5.8% | 4/5 |
| 宁德时代 | 5.1% | - | 4.5% | - | - | 1/5 |
```

定义：

- **共识仓位**：≥3 只基金共同重仓
- **分歧仓位**：仅本基金重仓，同业均未持有
- **跟随仓位**：本基金与多数同业同时新增/增持

### 3. 与基准对比

- 行业超低配：相对沪深300 / 中证500 的行业权重差
- 风格暴露：大盘/小盘、价值/成长相对基准的偏离
- 行业轮动 timing：超配行业后续 3 个月是否跑赢基准

### 4. 同业调仓方向对比

对比本基金与同类基金在同期的调仓方向：

- 本基金增持、同业也增持 → 共识买入
- 本基金增持、同业减持 → 分歧看多
- 本基金减持、同业增持 → 分歧看空
- 本基金减持、同业也减持 → 共识卖出

## 有效性验证框架

### 1. 新增仓位效果验证

对每个新建仓位（本季首次进入前十），计算：

- **买入后 1 个月收益**：验证短期 timing
- **买入后 3 个月收益**：验证中期判断
- **相对基准超额收益**：剔除市场β影响
- **相对行业指数超额收益**：剔除行业β影响

判断标准：

| 结果 | 标准 |
|------|------|
| 有效 | 3 个月超额收益 > 5% |
| 较有效 | 3 个月超额收益 0-5% |
| 无效 | 3 个月超额收益 < 0% |

### 2. 清仓仓位效果验证

对每个清仓仓位（上期在前十，本期不在前十），计算清仓后 3 个月收益：

| 结果 | 标准 |
|------|------|
| 有效卖出 | 清仓后 3 个月跑输基准 ≥5% |
| 较有效 | 清仓后 3 个月跑输基准 0-5% |
| 错误卖出 | 清仓后 3 个月跑赢基准 |

### 3. 行业轮动 Timing 验证

对每次行业配置占比变化 ≥3pp 的切换，计算：

- 切换后 3 个月该行业指数相对基准的超额收益
- 切换前该行业指数是否已大幅上涨（判断是否为追涨）

### 4. 核心持仓贡献验证

对连续持有 ≥6 季度的核心持仓：

- 持有期间年化收益
- 相对基准年化超额
- 占组合权重 × 超额收益 = 估算贡献度

### 5. 集中度与风险控制

- 前十大占比波动标准差
- 前十大占比单季最大变化
- HHI 赫芬达尔指数：HHI = Σ(每只持仓占净值比)² × 10000

| HHI | 集中度 |
|-----|--------|
| >2500 | 高度集中 |
| 1500-2500 | 中度集中 |
| <1500 | 相对分散 |

### 6. 换手效率验证

- 获取基金半年报/年报披露的换手率
- 计算期间年化超额收益
- 判断：高换手是否带来高超额？是否存在无效交易？

## 报告写作规范

### 叙事风格

继承 `hv-analysis` 的写作风格：

- **叙事驱动**：纵向部分要讲出基金经理的决策故事，不是简单列表
- **节奏感**：段落长短交替，关键判断单独成段
- **敢下判断**：每个观点必须有数据支撑，是推测要明确标注
- **用人话写**：避免「赋能」「抓手」「闭环」等空洞词汇
- **回环呼应**：开头埋下的细节在结尾 callback

### 绝对禁区

- 套话：「首先...其次...最后」、「综上所述」、「值得注意的是」
- 空洞形容词：「赋能」、「抓手」、「打造闭环」
- 高频踩雷词：「说白了」、「意味着什么？」、「本质上」、「换句话说」
- 编造数据：搜不到的数据标注「数据待补/待验证」

### 图表要求

- 重仓时间轴用 Markdown 表格呈现
- 有效性评分用表格 + 星级呈现
- 关键数据变化可用 ASCII 进度条或热力图
