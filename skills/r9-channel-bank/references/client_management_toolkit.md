# 银行理财经理客户经营工具集

> 适用场景：银行网点理财经理对高净值/贵宾客户的电话邀约、面谈 KYC、资产配置建议书呈现、异议处理及分群经营。

---

## 一、电话邀约参考话术

### 1.1 邀约由头分类

| 由头类型 | 典型触发场景 |
|---------|------------|
| **行为事件** | 大额进出款、资产余额不足、交易增加或减少 |
| **产品事件** | 产品到期、新开卡、产品盈利或亏损、有客户喜欢的产品发行 |
| **人生阶段转变** | 结婚、生儿育女、地址变化、工作变化 |
| **外部事件** | 利率变化、股市大涨大跌、客户活动等 |

### 1.2 常用邀约话术

**大额进账**
> "您最近有大额资金进账，非常感谢您的支持，不知这些资金您打算作何安排？看我怎么能帮到您？"

**大额走款**
> "您这两天有大额走款，我对您的资产变动非常关注，因为会涉及我给您的投资建议的变动，我想了解一下这笔资金您准备做什么用呢？"

**资产余额不足**
> "您目前在我行资产余额已不足高净值客户门槛标准（如500万），如果连续三个月不达标可能会产生账户管理费，所以我提前提醒您一下，看您能否统筹安排好您的资金。"

**理财产品到期**
> "您的理财产品明天到期，近期理财产品额度很紧张、收益也处于下行通道。为更好地帮您打理好资产，我想重新为您进行规划，您看什么时候方便呢？"

**贵宾卡到卡**
> "您的贵宾卡到了，不知您什么时间有空来领卡？知道您平时很忙，难得与您见一次面，想借这个机会好好与您聊聊在我行的资金投资安排。"

**基金止盈/止损**
> "近期市场变化较大，我一直在帮您关注基金的表现，您的基金最近*个月/周浮动盈利5%（或10%）/亏损5%，达到了之前我与您沟通的止盈/损线，想跟您沟通下看是否需要进行调整呢？"

**人生阶段——装修搬家**
> "您房子装修得怎么样了？准备什么时候搬进去呢？等您装修完，我想跟您约个时间好好聊聊打理您在我行的资产问题。"

**人生阶段——升职**
> "听说您最近升职做大领导了？恭喜啊！我想您以后会更忙了，所以我想尽快与您见个面，好好聊聊怎么样更好地帮您打理好在我行的资产。"

**外部事件——股市波动**
> "这两天股市暴跌/股市开始反弹了，市场发生变化，之前我给您的投资规划和投资策略需要及时进行调整。"

**外部事件——利率下调**
> "最近存款利率又下调了，不知您是否也在关注？利率下调对我们的投资理财有非常大的影响，之前我给您的投资规划需要及时进行调整。"

**客户活动邀约**
> "我们周末有个贵宾讲坛，邀请了XX专家来介绍*季度市场投资策略，名额非常有限，我已经帮您预留一个位子。"

**资产配置邀约**
> "上次与您沟通时，我建议您需配置固定收益类/股票类/其他类/保险类资产，您也非常赞成这个建议，我已为您优选出合适的产品。"

### 1.3 约面访时间（二选一法则）

> "不知您是下周二下午有空还是下周四上午有空？我下周这两个时间有空，可以帮您做一个时间安排。"

注意：确定面访时间要二选一，不要问"您什么时候有空"；同时要突出你自己的时间也很宝贵。

### 1.4 电话邀约异议处理

| 客户反对 | 回应话术 |
|---------|---------|
| 没时间 | "我知道您一定很忙，为更好地打理好您在我行的资产，还是需要麻烦您抽一点点时间。您看[时间2选1]方便过来吗？" |
| 没钱 | "没关系，其实我邀约您过来主要是为您现有的资产状况做一个检视。您看[时间2选1]方便过来吗？" |
| 已经规划了 | "那很好啊，我也根据您的偏好给您设计了一份方案，希望给您多一种选择。您看[时间2选1]方便过来吗？" |
| 是不是又要卖产品 | "我想跟您沟通的不是产品，而是如何更好地进行财富整体规划。产品只是实现财富管理的工具。" |
| 产品亏损 | "我非常理解您的心情，我这次想邀请您过来，是为了与您详细沟通该产品情况并商量资产配置调整方案。" |
| 与家人商量 | "那很好啊，非常欢迎您和家人一起过来，这样我们可以当面更好地交流。" |
| 太远了 | "如果您不方便过来，我们也可约一个时间我上门拜访您。" |
| 没兴趣 | "很多客户尝试了之后都会觉得有帮助，您看[时间2选1]方便过来吗？" |

## 三、常见 KYC 问题集

### 3.1 公司及职位

- 您是做哪一个行业的？主要业务在本地还是外地？
- 目前行业经营情况如何？企业盈利状况如何？
- 企业现有多少员工？主要合作伙伴有哪些？在行业中的地位如何？
- 您如何看待行业未来的成长性？企业未来会考虑上市吗？
- 您是企业大股东吗？与其他股东一起经营吗？
- 您在公司的职位是？家人也在公司工作吗？
- 您做这一行有多长时间？以前做什么？

### 3.2 家庭与背景

- 您是学什么专业的？
- 您妻子/丈夫做什么工作？家里谁带小孩？
- 您有几个小孩？多大了？在做什么？未来会接手您的事业吗？
- 父母谁照顾？单独住还是一起住？有无兄弟姐妹？

### 3.3 往来银行与资产负债

- 您平时主要往来的银行有哪些？工资代发是哪家？
- 家庭资产主要放在几家银行？对其他银行服务满意吗？
- 您目前持有的房产多吗？有贷款吗？
- 企业目前资金富裕还是有需求？通过什么方式融资？
- 企业和家庭的资产负债率大概什么水平？

### 3.4 投资状况

- 您放在银行的资金主要来源于企业还是工资？银行理财收益是主要收入来源吗？
- 您清楚现有投资主要配置在哪些资产类型及产品上吗？
- 您怎么看投资风险和收益的关系？风险承受能力如何？
- 您目前投资的整体收益情况如何？满意吗？
- 您对 A 股/房地产/市场事件怎么看？平时通过什么渠道关注金融市场？
- 您是否做过境外投资/配置？最近收益如何？
- 您比较偏好稳健投资还是愿意承担一定风险博取较高收益？
- 您是否有坚决不愿意配置的领域？
- 您在炒股方面是自己操作还是别人帮您做？是否接受专业投资人打理？

### 3.5 投资目标与偏好

- 对放在我行这部分资金，您在投资期限方面是怎么考虑的？
- 我们希望在未来配置中增加权益类/另类/保障类产品，您觉得如何？
- 在期限搭配上，建议增加一部分中长期投资，您觉得呢？

### 3.6 兴趣爱好

- 您平时工作忙吗？休息时喜欢做什么？
- 您喜欢打高尔夫、收藏、旅游吗？

### 3.7 保障

- 您买过保险吗？买的什么？在哪里买的？基于什么考虑？
- 您对保险的看法是？

## 四、第一次 KYC 开放式问题集

1. 您现在资产的主要配置在哪些产品类型？为什么偏好这种产品类型？
2. 您的风险承受能力如何？
3. 您目前投资的收益情况如何？
4. 您对现在 A 股/房地产/市场事件怎么看？
5. 您了解什么是资产配置吗？
6. 您是否做过境外投资/配置？最近收益怎么样？
7. 我们希望在未来配置中增加权益类/另类/保障类产品，您觉得如何？
8. 您对在我行的资产期限/收益是怎么考虑的？是否考虑部分做中长期投资？
9. 您偏好稳健投资还是愿意承担一定风险博取较高收益？
10. 您是否有坚决不愿意配置的领域？原因是什么？
11. 您的资产全部配置在 XX 中，是否担心风险？如何看待？
12. 如果有一种方案可以提高整体收益性，您是否考虑？
13. 您在炒股方面是自己操作还是别人帮您做？选股思路怎样？
14. 您对黄金的避险功能认可吗？有投资经验吗？
15. 您准备在本行打理的资金规模大概多少？

## 五、第一次 KYC 最常见 10 个反对问题及应对

| 反对问题 | 应对要点 |
|---------|---------|
| 给我保本收益高的就行 | 目前保本收益约3-4%，配置目的是在可承受风险下达到收益要求 |
| 能不能写承诺书 | 资产配置在大概率下获得较好收益，但监管不允许承诺收益 |
| 之前配置效果不好 | 效果不好的原因通常是持有周期不够长或配置不合理 |
| 钱不多，不用折腾 | 资产配置是一种理念，资金多少没关系 |
| 我已经分散了 | 先了解做过哪些投资、渠道提供哪些服务，再分情况解决 |
| 朋友帮我炒股很赚钱 | 股票不仅二级市场，还可通过一级半、一级市场配置 |
| 钱荒时股债双杀怎么办 | 配置还包括对冲基金、房地产信托等低相关性资产 |
| 国内能做的太少 | 我们也搭建了海外投资平台 |
| 配置就是让我买产品 | 资产配置是方法，产品只是落地工具 |
| 钱都买短期理财 | 流动性越高收益越低，先了解为什么需要流动性 |

## 六、基于不同性格客户的建议书解读策略

### 6.1 四类客户性格

| 类型 | 特征 | 解读策略 |
|-----|------|---------|
| **猫头鹰型** | 注重逻辑与数据 | 数据详实、图表为主；侧重市场分析与投资逻辑 |
| **孔雀型** | 偏感性、喜欢被夸奖 | 以故事为主、多举例子；强调服务尊贵与品牌 |
| **老鹰型** | 自主决策、需要尊重 | 每项大类资产提供两个以上选择；结果导向 |
| **鸽子型** | 优柔寡断 | 给出最适合的产品；最好邀请家人朋友同往协助决策 |

### 6.2 客户关系阶段经营重点

| 阶段 | 特征 | 经营重点 |
|-----|------|---------|
| 介入期 | 不熟悉、未信任、本行资产不足20% | 品牌、服务、感性认识 |
| 了解期 | 逐步转入资产 | 优势、专业性、接触粘度 |
| 增长期 | 年增量占比高、存量不足50% | 资产配置建议书、市场分析、路演 |
| 稳定期 | 年增量占比高、存量超50% | 家族信托、全权委托、保障覆盖 |

### 6.3 不同性格客户常见反对问题

**老鹰型**
- "这个方案对我有什么好处？" → 简洁、表格、结果导向，直接给选择方案。
- "你不承诺收益为什么要做？" → 用定量模型，具体化收益概率。
- "比价" → 表达站在客户角度，说明努力，必要时负责人到场体现重视。

**鸽子型**
- "我其实什么都不懂" → 用图表和数据说明专业建议。
- "上次说的挺好但收益很差" → 市场经常变化，要不断跟踪。
- "太复杂了" → 用简单例子说明大类资产配置。

**孔雀型**
- "他行产品收益高" → 强调组合收益和可持续性。
- "别人的更好" → 用案例和细节教育客户。
- "人情压力" → 从需求出发，权衡人情和个人利益。

**猫头鹰型**
- "预期收益率是否可信？" → 历史不代表未来，重点看同收益下风险、同风险下收益。
- "配置比例是否最优？" → 组合有很多，给的建议比现状好，且受产品起点限制。

## 七、高净值特殊客群经营策略

### 7.1 极度保守型客户

**特征**：只买保本或低风险产品、对非合同承诺不信任、谨慎难建立信任。

**潜在风险**：资产过于集中现金类、利率下行中增值效应递减、再投资风险。

**经营策略**：
- 强调严谨工作方法和资产配置理念
- 介绍本行荣誉优势，树立可信赖形象
- 清楚理解客户流动性需求真实含义
- 循序渐进配置，优先保本或保本策略产品
- 挖掘保险、家族信托需求

**配置建议**：万能险锁定利率、保本基金提升弹性、中短期净值型理财解决流动性、保障型保险。

**亏损客群经营**：
- 核心：重建信任、重建信心、看到方向
- 第一步：检讨过失（客户自身原因/客户经理原因/配置不完整）
- 第二步：回顾市场发生了什么
- 第三步：列举资产配置实例
- 第四步：明确观点，提醒提前布局、不追涨杀跌

### 7.2 漠不关心型客户

**特征**：固定收益为主、大笔现金长期不管、路径依赖、认为理财收益不重要。

**经营策略**：
- 区分企业主客户、有特殊收益来源客户、普通无精力客户
- 对企业主：成立专项服务小组，重点资源倾斜，工具是家族办公室服务
- 对特殊收益来源客户：了解来源，避免用收益率 PK，培养信任
- 对普通客户：提供省心省力方案，可选全权委托、综合配置、类固定收益产品

### 7.3 自主决策型客户

**特征**：自主配置意愿强、选择多家银行、自认为懂资产配置、信息割裂。

**经营策略**：
- 肯定客户已采取的分散措施
- 探讨这些措施能否真正实现风险管理和收益提升
- 强调资产配置比例的科学性和动态调整
- 将客户行外资产与本行资产综合检视，定期沟通
- 用本行平台优势、专业能力和产品吸引行外资产

### 7.4 纯三方型客户（股票投资型）

**细分类型**：

| 类型 | 特征 | 策略 |
|-----|------|------|
| **专业型** | 有投资逻辑、经验丰富、业绩优异 | 再次 KYC；沟通结构化配资、股指期货对冲、一级半/一级市场、家族办公室保障 |
| **非专业听消息型** | 依赖消息、重仓集中、盲目乐观 | 不反驳，顺势引导；推荐并购类、股权类投资 |
| **交给第三方打理型** | 信任第三方、省心坐享收益 | 确认委托情况；沟通分散选择不同风格团队、一级市场机会、家族办公室服务 |

## 八、使用原则

1. **先由头，后目的**：从客户关心的行为/产品/人生/外部事件切入。
2. **先 KYC，后配置**：充分了解客户后再给方案。
3. **因人而异**：根据客户性格类型选择沟通方式。
4. **分群经营**：对保守型、漠不关心型、自主决策型、股票型客户采用不同策略。
5. **合规底线**：不承诺收益、适当性匹配、风险提示到位。
